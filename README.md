## 🚀 Featured Projects

### 🏃 [SinCity Stride](https://github.com/manvik0730v/hacknite) · [Live demo](https://sincitystride.vercel.app)
A gamified running app with a story. Track real GPS runs, finish quests, level up, and flip between a bright **Uptown** mode and a darker **SinCity** mode where you capture map districts. Includes friends, streak calendar, run history and cinematic story sequences.
`React` `Tailwind` `Node.js` `Express` `MongoDB` `Firebase Auth` `Leaflet / OpenStreetMap`
*Hackathon project, built with [Aryan Thumula](https://github.com/aryancapy-17).*

### 📡 [Offline Mesh Emergency Network](https://github.com/manvik0730v/Offline-mesh-emergency-network)
A mesh chat network in C that works with no internet. Nodes find each other, send direct messages, broadcast to everyone, and log message history. Uses UDP sockets and a separate receiver thread so you can type and receive at the same time.
`C` `UDP sockets` `POSIX threads` `Make`
*Forked from [ArushJain-697/Offline-mesh-emergency-network](https://github.com/ArushJain-697/Offline-mesh-emergency-network).*

### 🖥️ [IAS Machine Simulator](https://github.com/manvik0730v/IAS_arch)
A working simulator of the 1952 IAS computer. It has an assembler that turns assembly into 40-bit machine instructions, and a processor you can step through fetch and execute cycle by cycle while watching PC, AC, MQ, IR, MAR and IBR change. Memory is a text file that updates live when you `STOR`.
`Python` `Assembler` `Computer Architecture`

### ♟️ [PyChess](https://github.com/manvik0730v/Two-Player-Chess-Command-Line-Interface-)
Two-player chess in the terminal with castling, pawn promotion, check, checkmate and stalemate detection. Pure Python with no dependencies, and the board is an 8×8 matrix of integer-coded pieces.
`Python` `CLI`
*Built with Debmalya Rath and Mohmad Abdul.*
